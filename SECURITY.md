# Security

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email **security@penopta.com** with:

- A description of the issue and impact
- Steps to reproduce (or a proof of concept)
- Affected routes, versions, or commit if known

We aim to acknowledge within a few business days. We will coordinate disclosure
and credit if you want it.

## Scope

This repository covers the Penopta web app (`penopta-app`). Related repos:

- [penopta-claude-plugin](https://github.com/sshadmand/penopta-claude-plugin)
- [penopta-linux-sync](https://github.com/sshadmand/penopta-linux-sync)
- Penopta Sync (macOS) — installer is a GitHub Release asset on this repo

Report issues in those repos to the same address if they affect Penopta users.

## Out of scope

- Social engineering against Penopta staff or users
- Denial-of-service against production without prior agreement
- Issues in third-party services (Google, GitHub, Vercel, Neon) unless introduced
  by our integration
