# Private docs (local only)

This folder is gitignored except for this README. Clone the public repo and it
will not be here.

Use it for unpublished plans, hosted-site checklists, and anything that is
only for maintainers. Do not commit files from here. Do not cite this folder
in public docs, comments, or commits.

Tracked product docs stay in `docs/` (`architecture.md`, screenshots) and
`AGENTS.md`.

Working plans go in `docs/private/plans/`.
